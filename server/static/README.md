# static/

Папка для статических файлов, раздаваемых сервером.

## gtnh_libs.zip

Содержит предварительно скачанные библиотеки GT:NH (libraries/ + versions/).
Лаунчер скачивает этот архив при первой установке вместо поштучного
обращения к Maven-репозиториям.

### Как обновить

На машине разработчика:

```bash
python download_libs.py          # скачивает/обновляет output_libs/
cd output_libs
zip -r ../server/static/gtnh_libs.zip .
```

Затем перезапустить сервер — эндпоинт `/api/downloads/libs/version`
вернёт новую версию (mtime+size), и лаунчеры автоматически
перекачают бандл при следующей установке.
